# ClimaAtlas Future

Website for the Term 3 project: design a future app or IT device.

## Project Idea

ClimaAtlas Future is a futuristic weather app based on the original weather API
project. Users search for a city and the app combines live weather, forecast,
country data and Wikipedia information. It also adds AI-style safety advice so
people understand what the weather means for real life.

## Assignment Requirements Covered

- What it is and main description
- The goal of the app
- Technical specifications and features
- Advantages and how it can improve people's lives
- Why it is the best app possible
- Video presentation script

## Why It Is The Best App Possible

ClimaAtlas Future explains the weather, it does not just display it.

Many weather apps show numbers, but ClimaAtlas Future explains what those
numbers mean for your day. It is the best option because it mixes real APIs,
useful recommendations, travel context and a clean interface.

## Video Presentation Script

## APIs Used

- Open-Meteo geocoding API
- Open-Meteo forecast API
- REST Countries API
- Wikipedia REST API
